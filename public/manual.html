Candidate Homepage Template

후보 정보만 넣으면 바로 쓰는 홈페이지 템플릿

새 후보 사이트를 만들 때는 src/data/candidate.ts를 먼저 수정하세요. 후보명, 정당명, 지역구, 약력, 공약, 지도 핀, SNS 링크가 한곳에 모여 있습니다.

필수 수정 항목

  • site: 후보명, 정당, 선거구, 슬로건, 도메인
  • profile: 소개 문구, 학력, 경력, 공개자료 안내
  • policies: 공약 제목, 분야, 요약, 추진 방향, 영상 링크
  • district: 지역 인구, 세대, 면적, 행정동 정보
  • mapCenter, mapPins: 지도 중심 좌표와 핀
  • assets: 히어로 이미지, 공유 이미지, 정당 로고 경로

이미지 교체

이미지는 public/images/에 넣고, 파일명이 다르면 assets의 경로를 함께 바꿉니다.

배포

수정 후 npm run build가 성공하면 main 브랜치에 반영하세요. GitHub Actions가 정적 사이트를 빌드해 GitHub Pages에 배포합니다.
